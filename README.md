## الأسعار وخيارات الكفالة
- **الكفالة الأساسية: 25 ر.ع شهرياً** — السعر المعلن حالياً في صفحة المنتج الرسمية (لاحظ
  أن صفحة المنتج على ووردبريس تعرض السعر بشكل خاطئ كـ "25,000 OMR" بسبب إعداد الكمية/الوحدة
  في ووكومرس — تم تجاهل هذا الخطأ التقني وعرض "25 ر.ع / شهرياً" كما هو موصوف نصياً في وصف
  المنتج نفسه وفي الملف التعريفي الرسمي).
- خيارات إضافية (25 / 35 / 60 / 10 ر.ع) مأخوذة من الملف التعريفي الرسمي (CV) ومعروضة
  كخيارات موثقة وليست بديلاً عن السعر الأساسي المعلن حالياً.
- الحد الأدنى لمدة الكفالة (سنة واحدة) مذكور في الصفحة بعبارة "بحسب ملف الجمعية المنشور"
  لتوضيح تاريخ ومصدر هذه المعلومة.
- الإحصائيات (عدد الأيتام، مبالغ الكفالات) معروضة كبيانات **تاريخية لعام 2023** فقط، بعلامة
  توضيحية واضحة، وليست أرقاماً حية.

## التتبّع (Tracking)
- الصفحة تحتفظ تلقائياً بمعاملات UTM/`fbclid`/`gclid` من رابط الإعلان وتُلحقها بكل روابط
  CTA الخارجية (`data-track="..."`).
- دالة `trackEvent()` في نهاية `index.html` جاهزة لربط Meta Pixel / Conversions API و
  Google Ads gtag — الأماكن المخصصة لإدخال المعرّفات الحقيقية موضّحة بتعليقات `PIXEL_ID` /
  `AW-CONVERSION_ID` / `CONVERSION_LABEL` داخل الكود.
- لم يتم لمس أو استبدال منطق الدفع/التبرع الفعلي — كل أزرار الكفالة توجّه مباشرة إلى صفحة
  المنتج الرسمية `bahjah.org.om/wp/product/برنامج-كفالة-يتيم/` أو صفحة التبرعات الرسمية.
